# 零点未读 · 中文网页推理游戏集

本仓库包含三款无需后端、打开网页即可游玩的中文推理游戏。仓库首页默认进入《零点未读》，另外两款作品使用独立目录与存档。

## 游戏入口

| 游戏 | 当前版本 | 入口 | 核心体验 |
| --- | --- | --- | --- |
| 零点未读 | 根目录版 · 存档 v2 | [开始调查](https://sakawa060209.github.io/zero-hour-unread/) | 台风夜档案室密室、延迟消息与五人证词 |
| 塞壬号：第七幕没有掌声 | v2.7.0 | [登上塞壬号](https://sakawa060209.github.io/zero-hour-unread/siren-seventh-act/) | 海上密室、证词污染、风暴压力与多路线举证 |
| 错层 | v3.8 | [进入临江壹号](https://sakawa060209.github.io/zero-hour-unread/wrong-floor/) | 主动观察、逐格人物核验、空间时间复原与玩家论证 |

GitHub Pages 地址分别为仓库根路径、`/siren-seventh-act/` 与 `/wrong-floor/`，三款游戏互不覆盖存档。

## 《零点未读》简介

台风“海琴”登陆前夜，五个人同时收到死者发来的消息。档案室从内部上闩，手机显示消息刚刚送达——但事实真是如此吗？

## 游玩方式

直接打开 `index.html`，或通过 GitHub Pages 访问。游戏支持：

- 八处现场调查与动态线索簿
- 五名嫌疑人的两轮审问：固定原话，再以“证词句子＋物证”完成反驳
- 酒窖、机房、温室、客房等自由调查地点
- 可交换的旧案残页、材料与受力点密室实验、无时间提示的乱序时间线
- 完整案件报告与三证据最终反驳
- 求真、审判、共情三种心理倾向
- 多结局、隐藏结局与浏览器本地自动存档

## 本地运行

这是纯静态项目。可以直接打开 `index.html`，也可以运行任意静态文件服务器：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 技术说明

项目仅使用 HTML、CSS 与原生 JavaScript，不依赖框架或构建步骤。
