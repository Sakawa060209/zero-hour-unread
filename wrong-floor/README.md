# 错层

《错层》v3.1 是一款纯 HTML、CSS 与原生 JavaScript 制作的单人网页推理游戏。

> 如果所有证据都是真的，为什么结论会是假的？

玩家以外聘案件分析员身份调查“临江壹号死亡案”，在八章与终章中完成现场勘查、时间线重排、建筑图叠加、双房对照、证据语义拆分、证词拆解、知识范围筛选和最终案件重构。

## 内容

- 8 章 + 终章、12 个核心推理
- 随推理逐步显影、绝不提前写入真相的动态时间线
- 原始观察、证据、推论分层记录；支持人物/来源筛选与三条钉选
- 六名相关人员的三轮询问：选择话题、在调查板选择外查来源、拆解语言并自由举证
- 三阶段空间推理、三阶段建筑图比较、观察与推论分离的双房调查、三层视线模拟
- 以排除理由代替 24 格机械填写的条件交集表，以及可点击连接的卷宗责任链
- 完整报告一致性校验，拒绝“选齐线索就通关”
- 浴室渗漏复现实验、关联证据视图与来源独立性标签
- 从全部案件材料中组合 1—3 条证据，完成支持等价路线并解释闭环原因的最终指认
- 4 个可自然到达的结局、人物后日谈与独立结局档案
- v1/v2/v3 存档迁移、本地自动存档、移动端适配、无构建静态部署

## 本地运行

在仓库根目录启动任意静态服务器：

```bash
python -m http.server 4173
```

访问 `http://127.0.0.1:4173/wrong-floor/`。

## 测试

`tests/logic.test.js` 覆盖章节门槛、证据组合、排除理由、卷宗双重连接、理论校验、报告一致性、存档迁移与结局判定。`tests/smoke.test.js` 使用 Playwright 完成不注入进度的 A/C/D 自然结局流程，并检查 B 结局、错误外查不发关键证据、提前剧透、关联证据、渗漏时间、存档续玩、P05 触控区域、P10 粘性首列与移动端横向溢出。
