# 错层

《错层》v3.7 是一款纯 HTML、CSS 与原生 JavaScript 制作的单人网页推理游戏。本版减少界面对答案的预先标注，让关键结论更多来自玩家主动打开材料、比较来源并完成推理操作。

> 如果所有证据都是真的，为什么结论会是假的？

玩家以外聘案件分析员身份调查“临江壹号死亡案”，在九章与终章中完成现场勘查、容差测量、建筑图叠加、双房对照、证据语义净化、人物查证、犯罪时间轴和最终案件重构。

## 内容

- 9 章 + 终章、14 个核心推理与 4 个可自然到达的结局
- 第一章使用可点击的 1102 俯视现场；四个核心热点构成推进条件，其余观察点可随时回看，尸体伤情与地毯观察组合后才形成初检材料
- P03 取消答案刻线，分别移动照片与图纸标尺的 A／B 端点，以带容差的双读数判断约 13 厘米异常；P04 支持 2012／2019 图纸叠加
- P05 在双房找不同后继续区分固定结构、可移动陈设、历史改造与当晚异常；P06 改为 11F—15F 动态视线模拟
- P07 以“证据净化”划去记录未支持的词组，并在整组提交后统一反馈，避免逐项反应提前暴露答案
- 标明“直接记录 / 实验估算 / 证据推论”的动态时间线，每条确定事件均可追溯来源
- 原始观察、证据、推论分层记录；支持人物/来源筛选与三条钉选
- 六名相关人员采用不同核验语境：主动核验、设备外查、措辞限定、来源校正、动机排除与延后回审；关键人物可在新增材料后再次询问
- 四阶段空间推理：容差测量、暂存假说、固定结构复核、最终裁决
- 逐单元绑定来源的条件交集；权限、身份、时间窗口与实际行为不再互相代替
- 尸表初检与伤情／设备联合复核分阶段释放；第一章不再提前给出隐藏现场或精确死亡区间
- 锁具认证与门磁开合使用两条互补记录；凭证、门扇和人员通过不再混写
- 第八章把物业审计与卡柜／服务区记录拆成可逐份打开的资料包；界面不预先标出唯一交集，玩家需先从六人中自主确认候选，再证明其条件
- 第九章以可拖动犯罪时间轴排列放水、取卡、搬运、挂链与离开，并从含干扰项的材料池连接时间、路径与锁闭来源
- 岗位接触条件与本人培训访问分开判断；智能手表只固定冲击与生理变化，派生复核才形成死亡区间
- 十项报告区分“现场置换者”与“致命冲突行为人”；四项已核验基础事实可一次采用，死亡地点、持卡人和门链离场仍需逐项确认，其余判断由玩家填写
- 报告草稿与已验证快照分离；通过后任何修改都会暂停公开提交，重新复核后可继续且无需重做举证
- 报告字段、复原来源、举证勾选与摘要展开状态实时保存；从案件簿可返回原章节、原步骤或当前举证
- 终章压缩为“死亡地点、致命冲突行为人、封存卷宗”三项核心质询；未查旧案时只需前两项
- 最终举证允许加入相关补强，拒绝无关材料，并按当前选择反馈“已经证明到哪里、还缺哪段连接”
- 进行中的旧版举证按规则版本迁移；当前有效、旧版完成与需要复核三种状态不会混写
- 举证完成、等待公开决定、已结案三态分离，关闭弹窗或刷新后仍可继续提交
- 白色主画布与浅灰绿案件面板；现场、系统、图纸、法医、私人材料和封存卷宗使用不同纸张视觉，并强化现场、图纸与人物核验三个关键场景的层次
- 建筑关系图随推理逐步揭示 1402、共用管井、服务路线、检修口与完整复原路径
- “误判”改为“推理修正”，正常结案按修正次数显示“严谨／稳健／需复核”；错误结案固定标明“错误结案”，评级不改变剧情结局
- 手机端保留文字热点、上下排序、材料连接、滚动与键盘焦点；桌面端同时支持拖放
- v1—v9 存档迁移到 v10 状态结构；进行中、等待公开决定和已结案记录分别校验，旧版题序与结案证明只读封存，不会冒充 v3.7 当前规则通过

## 本地运行

在仓库根目录启动任意静态服务器：

```bash
python -m http.server 4173
```

访问 `http://127.0.0.1:4173/wrong-floor/`。

## 测试

首次运行：

```bash
cd wrong-floor
npm install
npx playwright install chromium
npm test
```

`npm run test:logic` 覆盖十章门槛、P03 双端点与容差、P05 分类、P07 净化、自主候选、三类材料统计、犯罪时间轴、报告批量／逐项采用与快照失效、2／3 轮终章、四结局守卫及 V1—V9 存档迁移。`npm run test:smoke` 使用 Playwright 完成 A/C/D 自然结局，并检查 B 错误结案、资料包逐份查阅、信息释放、报告修改后失效与恢复、公开决定中断恢复、跨案件簿与刷新后的草稿、选中材料筛选边界、旧版举证封存，以及 320px 触控、焦点和浅色响应式视图。若使用已有浏览器，可显式设置 `PLAYWRIGHT_BROWSER` 为浏览器可执行文件路径；测试默认使用 Playwright 自己安装的 Chromium，不依赖 Windows Edge。
