# 错层

《错层》v3.5 是一款纯 HTML、CSS 与原生 JavaScript 制作的单人网页推理游戏。

> 如果所有证据都是真的，为什么结论会是假的？

玩家以外聘案件分析员身份调查“临江壹号死亡案”，在八章与终章中完成现场勘查、时间线重排、建筑图叠加、双房对照、证据语义拆分、证词拆解、知识范围筛选和最终案件重构。

## 内容

- 8 章 + 终章、14 个核心推理
- 标明“直接记录 / 实验估算 / 证据推论”的动态时间线，每条确定事件均可追溯来源
- 原始观察、证据、推论分层记录；支持人物/来源筛选与三条钉选
- 六名相关人员的三轮询问：选择话题、在调查板选择外查来源、拆解语言并自由举证
- 四阶段空间推理：容差测量、暂存假说、固定结构复核、最终裁决
- 逐单元绑定来源的条件交集；权限、身份、时间窗口与实际行为不再互相代替
- 尸表初检与伤情／设备联合复核分阶段释放；第一章不再提前给出隐藏现场或精确死亡区间
- 锁具认证与门磁开合使用两条互补记录；凭证、门扇和人员通过不再混写
- 玩家亲自排列放水、取卡、搬运、挂链与离开，并为每一步连接主要依据和时间／路径补充；来源不足时不会生成精确复原
- 岗位接触条件与本人培训访问分开判断；智能手表只固定冲击与生理变化，派生复核才形成死亡区间
- 十项报告区分“现场置换者”与“致命冲突行为人”；七项已成立事实自动带入，三项判断由玩家确认
- 报告草稿与已验证快照分离；通过后任何修改都会暂停公开提交，重新复核后可继续且无需重做举证
- 报告字段、复原来源、举证勾选与摘要展开状态实时保存；从案件簿可返回原章节、原步骤或当前举证
- 最终举证允许加入相关补强，拒绝无关材料，并按当前选择反馈“已经证明到哪里、还缺哪段连接”
- 进行中的旧版举证按规则版本迁移；当前有效、旧版完成与需要复核三种状态不会混写
- 举证完成、等待公开决定、已结案三态分离，关闭弹窗或刷新后仍可继续提交
- 白色主画布、浅灰绿案件面板与高对比状态色；手机端人物排除卡、标尺 ±1 微调、复原顺序按钮、滚动与键盘焦点保持
- 4 个可自然到达的结局、人物后日谈与独立结局档案
- v1—v7 存档迁移、旧版证明与复原记录独立封存、存储失败保护、移动端适配、无构建静态部署

## 本地运行

在仓库根目录启动任意静态服务器：

```bash
python -m http.server 4173
```

访问 `http://127.0.0.1:4173/wrong-floor/`。

## 测试

首次运行：

```bash
cd wrong-floor
npm install
npx playwright install chromium
npm test
```

`npm run test:logic` 覆盖章节门槛、认证／门磁语义、逐单元证据状态、复原双来源、置换者／致命行为人分离、报告快照、针对性举证反馈、六轮结案守卫与 V1—V7 存档迁移。`npm run test:smoke` 使用 Playwright 完成 A/C/D 自然结局，并检查 B 结局、信息释放、报告修改后失效与恢复、公开决定中断恢复、跨案件簿与刷新后的草稿、选中材料筛选边界、旧版举证复核，以及 320px 触控、焦点和浅色响应式视图。若使用已有浏览器，可显式设置 `PLAYWRIGHT_BROWSER` 为浏览器可执行文件路径；测试默认使用 Playwright 自己安装的 Chromium，不依赖 Windows Edge。
