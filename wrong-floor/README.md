# 错层

《错层》v3.9 是一款纯 HTML、CSS 与原生 JavaScript 制作的单人网页推理游戏。本版让旧判断会随新证据失效，并统一直接记录、派生复核、推定窗口与玩家论证的证明边界。

> 如果所有证据都是真的，为什么结论会是假的？

玩家以外聘案件分析员身份调查“临江壹号死亡案”，在九章与终章中完成现场勘查、容差测量、建筑图叠加、双房对照、证据语义净化、人物查证、犯罪时间轴和最终案件重构。

## 内容

- 9 章 + 终章、14 个核心推理与 4 个可自然到达的结局
- 第一章使用可点击的 1102 俯视现场；四个核心热点构成推进条件，其余观察点可随时回看，尸体伤情与地毯观察组合后才形成初检材料
- P03 分别校验照片与图纸的 A／B 端点位置及读数容差，相同差值但端点错位不再通过；图上辅助线与标尺同步移动，四个端点均有 ±1 微调
- P04 必须查看旧图、现图与叠合三种模式；热点以“疑似改动”呈现，局部观察后才说明门位、固定边界与管井差异
- P05 六项正确分类即可推进，“当前材料无法判断”改为审慎观察加成而非隐藏门槛；手机端可在 1102、14F 与叠合视图间切换
- P06 只有点击“记录当前投影”才计入比较，按钮文字与真实楼层同步；保存后的多投影会并列比较，最终还需选择几何依据
- P07 以“证据净化”划去记录未支持的词组，八类材料各有对应边界提示；提示次数与错误提交次数分开记录
- 标明“直接记录 / 实验估算 / 证据推论”的动态时间线，每条确定事件均可追溯来源
- 原始观察、证据、推论分层记录；支持人物/来源筛选与三条钉选
- 六名相关人员采用不同核验语境：主动核验、设备外查、措辞限定、来源校正、动机排除与延后回审；关键人物可在新增材料后再次询问
- 四阶段空间推理：容差测量、暂存假说、固定结构复核、最终裁决
- 逐单元绑定来源的条件交集；权限、身份、时间窗口与实际行为不再互相代替
- 尸表初检与伤情／设备联合复核分阶段释放；第一章不再提前给出隐藏现场或精确死亡区间
- 锁具认证与门磁开合使用两条互补记录；凭证、门扇和人员通过不再混写
- 第八章把物业审计与卡柜／服务区记录拆成可逐份打开的资料包；24 格工作表先判断、后连接来源，并可在玩家原始研判与系统核验结果之间切换
- 工作表通过时保存证据签名；后续新材料只标记受影响格并撤销旧核验，原填写与逐格修改历史不会丢失；旧版完成记录明确标为迁移推论
- 顾雪可由复制缩略图证明接触过 1402 历史资料，却没有受控实施权限；嫌疑收束必须继续依赖权限、时间与具体行为交集
- 第九章先把锁具认证与门磁流合成“21:41 正门事件复核”，再引用到可拖动犯罪时间轴；它仍不证明身份、方向或载物
- 复原图明确区分直接记录、实验／派生复核与 21:24—21:37 推定搬运窗口，不再把 21:24 写成精确搬运起点
- 岗位接触条件与本人培训访问分开判断；智能手表只固定冲击与生理变化，派生复核才形成死亡区间
- 十三项报告区分“现场置换者”与“致命冲突行为人”；三条核心论证均由结论、物理／行为来源、独立复核与证明边界四部分生成
- 终章保留初始空间假说、审慎观察、提示次数、工作表修订与旧案标记；结案后另有调查方法复盘
- 报告草稿与已验证快照分离；通过后任何修改都会暂停公开提交，重新复核后可继续且无需重做举证
- 报告字段、复原来源、举证勾选与摘要展开状态实时保存；从案件簿可返回原章节、原步骤或当前举证
- 终章压缩为“死亡地点、致命冲突行为人、封存卷宗”三项核心质询；未查旧案时只需前两项
- 最终举证允许加入相关补强，拒绝无关材料，并按当前选择反馈“已经证明到哪里、还缺哪段连接”
- 进行中的旧版举证按规则版本迁移；当前有效、旧版完成与需要复核三种状态不会混写
- 举证完成、等待公开决定、已结案三态分离，关闭弹窗或刷新后仍可继续提交
- 白色主画布与浅灰绿案件面板；现场、系统、图纸、法医、私人材料和封存卷宗使用不同纸张视觉，并强化现场、图纸与人物核验三个关键场景的层次
- 建筑关系图随推理逐步揭示 1402、共用管井、服务路线、检修口与完整复原路径
- “误判”改为“推理修正”，正常结案按修正次数显示“严谨／稳健／需复核”；错误结案固定标明“错误结案”，评级不改变剧情结局
- 手机端保留文字热点、上下排序、材料连接、滚动与键盘焦点；桌面端同时支持拖放
- v1—v11 存档迁移到 v12 状态结构；进行中、等待公开决定和已结案记录分别校验，旧版题序、工作表与结案证明均带来源标识，不会冒充 v3.9 当前规则通过

## 本地运行

在仓库根目录启动任意静态服务器：

```bash
python -m http.server 4173
```

访问 `http://127.0.0.1:4173/wrong-floor/`。

## 测试

首次运行：

```bash
cd wrong-floor
npm install
npx playwright install chromium
npm test
```

`npm run test:logic` 覆盖十章门槛、P03 图上端点、P04 叠图、P05 审慎加成、P06 投影理由、P07 八类提示、P10 证据签名与逐格历史、复合正门事件、结构化报告、四结局守卫及 V1—V11 存档迁移。`npm run test:smoke` 使用 Playwright 完成 A/C/D 自然结局，并检查 B 错误结案、证据不齐时先核验工作表后再补证、核验后重新编辑、P07 提示独立计数、P06 按钮同步、复原证据层级、报告修改后失效与恢复、320px 触控及浅色响应式视图。若使用已有浏览器，可显式设置 `PLAYWRIGHT_BROWSER` 为浏览器可执行文件路径；测试默认使用 Playwright 自己安装的 Chromium，不依赖 Windows Edge。
