# 错层

《错层》v3.4 是一款纯 HTML、CSS 与原生 JavaScript 制作的单人网页推理游戏。

> 如果所有证据都是真的，为什么结论会是假的？

玩家以外聘案件分析员身份调查“临江壹号死亡案”，在八章与终章中完成现场勘查、时间线重排、建筑图叠加、双房对照、证据语义拆分、证词拆解、知识范围筛选和最终案件重构。

## 内容

- 8 章 + 终章、14 个核心推理
- 标明“直接记录 / 实验估算 / 证据推论”的动态时间线，每条确定事件均可追溯来源
- 原始观察、证据、推论分层记录；支持人物/来源筛选与三条钉选
- 六名相关人员的三轮询问：选择话题、在调查板选择外查来源、拆解语言并自由举证
- 四阶段空间推理：容差测量、暂存假说、固定结构复核、最终裁决
- 逐单元绑定来源的条件交集；权限、身份、时间窗口与实际行为不再互相代替
- 尸表初检与伤情／设备联合复核分阶段释放；第一章不再提前给出隐藏现场或精确死亡区间
- 玩家亲自排列放水、取卡、搬运、挂链与离开，并为每一步连接主要依据和时间／路径补充；来源不足时不会生成精确复原
- 岗位接触条件与本人培训访问分开判断；智能手表只固定冲击与生理变化，派生复核才形成死亡区间
- 十项报告一致性校验按“地点连接 / 身份归属 / 时间锚点 / 锁闭复原”等类别反馈
- 报告字段、复原来源、举证勾选与摘要展开状态实时保存；从案件簿可返回原章节、原步骤或当前举证
- 最终举证允许加入相关补强，拒绝无关材料，并明确派生材料与原始来源不重复计为独立支持
- 举证完成、等待公开决定、已结案三态分离，关闭弹窗或刷新后仍可继续提交
- 手机端人物排除卡、标尺 ±1 微调、复原顺序按钮、滚动与键盘焦点保持
- 4 个可自然到达的结局、人物后日谈与独立结局档案
- v1—v6 存档迁移、旧版证明与复原记录独立封存、存储失败保护、移动端适配、无构建静态部署

## 本地运行

在仓库根目录启动任意静态服务器：

```bash
python -m http.server 4173
```

访问 `http://127.0.0.1:4173/wrong-floor/`。

## 测试

首次运行：

```bash
cd wrong-floor
npm install
npx playwright install chromium
npm test
```

`npm run test:logic` 覆盖章节门槛、逐单元证据状态、初检／联合复核依赖、复原顺序与双来源、补强举证、六轮结案状态、报告分类反馈、理论校验与 V1—V6 存档迁移。`npm run test:smoke` 使用 Playwright 完成不注入进度的 A/C/D 自然结局，并检查 B 结局、章节剧透、公开决定中断恢复、跨案件簿与刷新后的草稿、玩家现场复原、旧版复原界面、存储写入失败，以及 320px 触控全流程、焦点和响应式边界。若使用已有浏览器，可显式设置 `PLAYWRIGHT_BROWSER` 为浏览器可执行文件路径；测试默认使用 Playwright 自己安装的 Chromium，不依赖 Windows Edge。
