# 错层

《错层》v3.2 是一款纯 HTML、CSS 与原生 JavaScript 制作的单人网页推理游戏。

> 如果所有证据都是真的，为什么结论会是假的？

玩家以外聘案件分析员身份调查“临江壹号死亡案”，在八章与终章中完成现场勘查、时间线重排、建筑图叠加、双房对照、证据语义拆分、证词拆解、知识范围筛选和最终案件重构。

## 内容

- 8 章 + 终章、12 个核心推理
- 标明“直接记录 / 实验估算 / 证据推论”的动态时间线，每条确定事件均可追溯来源
- 原始观察、证据、推论分层记录；支持人物/来源筛选与三条钉选
- 六名相关人员的三轮询问：选择话题、在调查板选择外查来源、拆解语言并自由举证
- 四阶段空间推理：容差测量、暂存假说、固定结构复核、最终裁决
- 逐单元绑定来源的条件交集；权限、身份、时间窗口与实际行为不再互相代替
- 取卡活体认证、服务区路径、浴室检修口及门链复原，闭合 20:46—21:49 的现场置换顺序
- 十项报告一致性校验按“地点连接 / 身份归属 / 时间锚点 / 锁闭复原”等类别反馈
- 最终举证可展开证据摘要，失败保留选择，成功说明严格对应实际提交路线
- 手机端人物排除卡、标尺 ±1 微调、滚动与焦点保持
- 4 个可自然到达的结局、人物后日谈与独立结局档案
- v1/v2/v3/v4 存档迁移、存储失败保护、移动端适配、无构建静态部署

## 本地运行

在仓库根目录启动任意静态服务器：

```bash
python -m http.server 4173
```

访问 `http://127.0.0.1:4173/wrong-floor/`。

## 测试

首次运行：

```bash
cd wrong-floor
npm install
npx playwright install chromium
npm test
```

`npm run test:logic` 覆盖章节门槛、逐单元证据状态、因果链缺项、全部举证路线、报告分类反馈、理论校验与 V1—V4 存档迁移。`npm run test:smoke` 使用 Playwright 完成不注入进度的 A/C/D 自然结局，并检查 B 结局、分阶段刷新、错误外查、门链复原、缺证反馈、存储写入失败、触控标尺与热点，以及 320/360/390px 和横屏布局。若使用已有浏览器，可显式设置 `PLAYWRIGHT_BROWSER` 为浏览器可执行文件路径；测试不再默认依赖 Windows Edge。
