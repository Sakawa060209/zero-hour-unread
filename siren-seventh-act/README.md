# 塞壬号：第七幕没有掌声

独立的中文海上密室文字推理网页游戏。项目与仓库根目录的《零点未读》并列，不替换原项目。

## 入口

直接打开本目录中的 `index.html`，或在 GitHub Pages 根地址后访问：

```text
/siren-seventh-act/
```

## 游戏系统

- 七名案件角色、六名可审讯嫌疑人
- 七个调查区域与 35 项限时行动
- 痕迹、信息、关联、解释、证据五阶段线索
- 假说驱动的二次调查
- 四条按核心子集、独立来源、合法补强与最低证明分判定的证据链
- 四选二原始口供、平衡的问题收益、信任专属线索、行为/动机分离的纯物证证明与有效证词污染
- 三层图纸、双声道磁带、三个七号房、水位、关系网络传播追踪与动态时间线谜题
- 四选三大型检验与等价替代路线、真实证据降级、不可逆的三阶段船体危机与强制撤离
- 带入场门槛、人物专属反证与秘密现场反应的最终剧场对质
- 按证据链/来源筛选与案卷重点标记、自动生成且参与结案判定的报告附件
- 七部分最终案件报告、严格核对错误证据链的十五类结局、秘密条件后日谈
- 结局页调查耗时、错误、提示、污染证词与纯物证证明统计
- 跨周目“剧场座位”正式图鉴、半透明复盘预演与分结局安全纪录
- 三档具有不同规则的难度、浏览器自动存档、可选风暴环境音

## 技术

纯 HTML、CSS 和原生 JavaScript，无构建步骤、无后端依赖。
