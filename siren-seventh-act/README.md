# 塞壬号：第七幕没有掌声

独立的中文海上密室文字推理网页游戏。项目与仓库根目录的《零点未读》并列，不替换原项目。

当前版本：v2.7.0。

## 入口

直接打开本目录中的 `index.html`，或在 GitHub Pages 根地址后访问：

```text
/siren-seventh-act/
```

## 游戏系统

- 七名案件角色、六名可审讯嫌疑人
- 七个调查区域与 36 项限时行动
- 痕迹、信息、关联、解释、证据五阶段线索
- 假说驱动的二次调查
- 四条按核心子集、独立来源、合法补强与最低证明分判定的证据链
- 四选二原始口供、按见证人独立性动态计分的衍生证言、信任专属线索与有效证词污染
- 三层图纸、双声道磁带、三个七号房、水位、关系网络传播追踪与可直接上下移动的十四节点时间线谜题；选项位置按局随机，每题使用独立提示
- 四选三大型检验与等价替代路线、设有 45 分钟期限且任意两组均可闭合物证的录像残余抢救、不可逆的三阶段船体危机与强制撤离
- 按累计调查分钟结算的风暴损耗，短操作不重复计罚；普通模式以 90% 船体安全开始，每 36 分钟才扣 1 点，旧普通存档迁移时一次性补充 12 点
- 普通模式按调查进度触发三次动态掩盖事件及至少一次弱化危机；嫌疑人的擦洗、删除和转移行为会留下可用于证据链的新线索
- 带中性入场门槛、分难度反证提示、秘密现场反应与危机回流的最终剧场对质
- 按证据链/来源筛选与案卷重点标记、自动生成且参与结案判定的报告附件
- 七部分最终案件报告、密封/有限/全部公开级别、严格核对错误证据链的十五类结局
- 结局页调查耗时、错误、提示、污染证词、纯物证证明与调查风格称号
- 极难证据链在三次失败后可消耗 15 分钟复核，复核后不再循环锁定
- 跨周目“剧场座位”正式图鉴、半透明复盘预演（包括撤离结局）与分结局安全纪录
- 三档具有不同规则的难度、浏览器自动存档、可选风暴环境音

## 技术

纯 HTML、CSS 和原生 JavaScript，无构建步骤、无后端依赖。
