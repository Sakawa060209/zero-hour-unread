# 塞壬号：第七幕没有掌声

独立的中文海上密室文字推理网页游戏。项目与仓库根目录的《零点未读》并列，不替换原项目。

## 入口

直接打开本目录中的 `index.html`，或在 GitHub Pages 根地址后访问：

```text
/siren-seventh-act/
```

## 游戏系统

- 七名案件角色、六名可审讯嫌疑人
- 七个调查区域与 33 项限时行动
- 痕迹、信息、关联、解释、证据五阶段线索
- 假说驱动的二次调查
- 四条需要玩家亲自组合的证据链
- 三轮动态审讯、话题封闭、虚假认罪与有效证词污染
- 三层图纸、双声道磁带、三个七号房、水位与动态时间线谜题
- 三次大型检验限制、证据降级、三阶段船体危机与强制撤离
- 七部分最终案件报告、十三类结局、秘密条件后日谈
- 首次结案锁定、结局图鉴与复盘模式
- 三档具有不同规则的难度、浏览器自动存档、可选风暴环境音

## 技术

纯 HTML、CSS 和原生 JavaScript，无构建步骤、无后端依赖。
