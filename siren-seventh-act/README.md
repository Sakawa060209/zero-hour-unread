# 塞壬号：第七幕没有掌声

独立的中文海上密室文字推理网页游戏。项目与仓库根目录的《零点未读》并列，不替换原项目。

## 入口

直接打开本目录中的 `index.html`，或在 GitHub Pages 根地址后访问：

```text
/siren-seventh-act/
```

## 游戏系统

- 七名案件角色、六名可审讯嫌疑人
- 七个调查区域与 35 项限时行动
- 痕迹、信息、关联、解释、证据五阶段线索
- 假说驱动的二次调查
- 四条按核心子集、独立来源、合法补强与最低证明分判定的证据链
- 两题原始口供、信任专属线索、话题封闭、虚假认罪与有效证词污染
- 三层图纸、双声道磁带、三个七号房、水位、传播追踪与动态时间线谜题
- 四选三大型检验与等价替代路线、真实证据降级、三阶段船体危机与强制撤离
- 自动生成且参与结案判定的报告证据附件
- 七部分最终案件报告、十四类结局、秘密条件后日谈
- 跨周目“剧场座位”结局图鉴、首次结案记录与复盘模式
- 三档具有不同规则的难度、浏览器自动存档、可选风暴环境音

## 技术

纯 HTML、CSS 和原生 JavaScript，无构建步骤、无后端依赖。
