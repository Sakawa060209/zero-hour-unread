# 塞壬号：第七幕没有掌声

独立的中文海上密室文字推理网页游戏。项目与仓库根目录的《零点未读》并列，不替换原项目。

## 入口

直接打开本目录中的 `index.html`，或在 GitHub Pages 根地址后访问：

```text
/siren-seventh-act/
```

## 游戏系统

- 七名案件角色、六名可审讯嫌疑人
- 七个调查区域与 30 项限时行动
- 痕迹、信息、关联、解释、证据五阶段线索
- 假说驱动的二次调查
- 警觉、压力、保护谎言与证词污染
- 三层图纸、双声道磁带、三个七号房、水位、双时间线谜题
- 船体安全与证物保存系统
- 七部分最终案件报告、八类主结局、秘密公开与船体状态后日谈
- 三档难度、浏览器自动存档、可选风暴环境音

## 技术

纯 HTML、CSS 和原生 JavaScript，无构建步骤、无后端依赖。
